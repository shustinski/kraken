## Исходный аудит до исправлений

## Решение о выпуске

**Текущая версия не готова к передаче пользователям.** Реальный сценарий через
интерфейс доходит до обучения NeuralImage, но обучение завершается ошибкой
`NameError: name 'TrainerProcess' is not defined`. Это функциональный отказ,
не оценка качества нейросети. Получение модели, распознавание этой новой
моделью и последующие шаги нового полного прогона не подтверждены.

Проверена версия `8c6c441` (`refactor`) вместе с текущими изменениями рабочего
дерева. После предыдущего аудита рефакторинг затронул 1426 файлов.
Три существовавших перед аудитом изменения в `run_manager_gui.py`,
`load_remote_auth_env.py` и `register_local.py` сохранены.
Результаты от 13 октября не считаются подтверждением текущей версии.

- Отдельный Server `127.0.0.1:58080`, Blob Gateway `58081`, PostgreSQL `55432`.
- Для Admin создана отдельная база `kraken_audit_tests_20261015`; тесты
  дополнительно используют собственные схемы и временные каталоги.
- Исходники: `D:\OZI\Нейронка\kraken_test_project\l1`, 100 JPEG.
  Все 100 SHA-256 совпадают с сохранёнными 13 октября.
- PyTorch `2.12.0+cu132`, CUDA `13.2`, `cuda.is_available() == True`,
  NVIDIA GeForce RTX 5070 Laptop GPU. Зависимости не пересинхронизировались.
- Реальные Qt-виджеты запускаются с `QT_QPA_PLATFORM=offscreen`, нажатия выполняет
  QTest. Выбор файлов и тестовые настройки автоматизированы; серверный транспорт,
  Contour и обучение не подменяются. Качество геометрии и обучения не является
  критерием приёмки.

## Серверная граница и пределы подтверждения

В UI-прогонах Hub не проверяет серверные исходные каталоги через `Path.is_dir`;
такие обращения в тесте явно запрещены. Contour получает серверные изображения
через API и виртуальные пути. Проверки checksum, разрешений доступа, server
streams и просмотра 100 кадров прошли. Сканирование и связывание исходной папки
выполняются сервером. Это подтверждает проверенные ветви Hub/Contour, но не
доказывает отсутствие прямого доступа во всех режимах каждого плагина.

Отдельный UI-прогон ранее завершённого проекта прошёл на текущем сервере:
проверены роли, 100 сохранённых CIF, распознавание существующей готовой моделью,
статистика 10 изменённых / 90 неизменённых результатов, экспорт CSV/XLSX,
отмена и удаление задания, удаление шага без потери представления. Использована
модель из проекта 13 октября: это не подтверждает успешность нового обучения.

В новом полном прогоне подтверждены создание проекта, сканирование/связывание
100 изображений, миниатюры, подготовка выборки и получение прямых CIF в Contour.
Обучение остановлено функциональной ошибкой; оставшуюся цепочку нового проекта
нельзя объявлять пройденной. Для остальных плагинов успешные unit-тесты не
означают наличия полноценного серверного workflow. Ограничения серверных
AnalysisRun/внешних плагинов из предыдущего аудита не считаются устранёнными.

Docker, установщики, Windows Service после перезагрузки, многопользовательская
нагрузка и все платформы не проверялись. Учётные данные стенда в отчёт не включены.

## Что необходимо перед выдачей пользователям

Восстановить runtime-зависимости обучения и распознавания NeuralImage, разобрать
оставшиеся падения тестов и проблемы диагностических импортов. Затем заново
пройти **весь** новый UI-сценарий до модели, двух веток CIF, выдачи работ,
приёма исправлений, статистики и отчётов; повторить открытие после перезапуска.
Положительное решение о выпуске возможно только после этого повторного прогона.
