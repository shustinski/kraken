## Закрыто средой, не отсутствием теста

Постоянный PostgreSQL для регистрации, проекта, слоя, заметки, плана работ, конфликта ревизии, роли наблюдателя и перезапуска исполнен на отдельной схеме в `kraken_local`. Нативный backup и двойной каталог Hub с этим сервером не исполнялись: копия затронула бы рабочую базу, а у `kraken_local_app` нет права `CREATEDB`.

`tests/test_end_to_end_functional.py` в этом сеансе исполнен. Он закрывает синтетический путь векторизации, обучения, масок, анализа, сшивки, электрического экспорта и backup. Он не закрывает качество модели и электрическую приёмку реального прибора: квитанция сама ставит эти флаги в false. Первый запуск упёрся в недоступный каталог pytest, повтор с отдельным `--basetemp` прошёл.

`tests/test_live_ui_workflow.py` требует `KRAKEN_UI_TEST_CONFIG` и живой сервер. Не исполнялся.

## Группы без сквозной проверки в этом сеансе

Продолжать аудит с этих пунктов:

1. Диалоги Qt плана, качества, физики, электрики, сшивки, анализа, ролей, поручения и статистики. Сервисные вызовы части из них уже PASS, кнопки диалогов — нет.
2. Запуск конвейера: векторизация Contour, обучение и распознавание NeuralImage, сшивка `layer.stitch.v1`, анализ Karakal. С настоящим агентом, без подмены `LocalAgentRuntime`.
3. Сервер на временной схеме PostgreSQL: создание проекта, слой, импорт, роль, перезапуск процесса, чтение. Затем backup и restore.
4. Связка Hub → сервер → Blob Gateway на одном проекте.
5. Окна плагинов offscreen: открыть файл, выполнить одну команду, закрыть. CSliser: копирование во временный каталог. KateGB: расчёт на фикстуре, если она есть в `plugins/kategb/tests`.
6. Ошибки: конфликт ревизии, чужая роль, отмена задания агента, повреждённый backup уже проверен локально.
7. Повторное открытие Hub как процесса `kraken-hub`, не только нового `EmbeddedProjectService`. Диалог создания это частично покрывает. Вход через окно логина — нет.

## Ложные зелёные зоны

- Архитектурные тесты границ модулей не говорят, что кнопка сохраняет данные.
- Opt-in тесты, не запущенные в этом сеансе, не переносятся в PASS.
- `kraken-server --development` не заменяет PostgreSQL.
- Успешный `--help` плагина не означает, что операция из Hub импортирует результат обратно в проект.
